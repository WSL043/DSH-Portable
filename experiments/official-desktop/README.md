# Retired alpha.1 source-overlay experiment

alpha.1 的源码覆盖、自建 ASAR、宿主端口补丁和对应旧门槛已退出当前开发树。新的 alpha.2 使用 [官方成品启动器](../official-payload/README.md)，不再维护第二套桌面壳。

The source-overlay build, rebuilt ASAR, host patch and old qualification gate were retired. Alpha.2 uses the [official payload launcher](../official-payload/README.md). Generic native test infrastructure was moved there rather than duplicated.

Historical reproducibility: [alpha.1 source](https://github.com/WSL043/DSH-Portable/tree/v1.0.0-alpha.1/experiments/official-desktop). Earlier audit documents describe that historical artifact, not the current implementation.
