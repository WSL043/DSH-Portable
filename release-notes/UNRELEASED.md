# 0.9.6 发布准备 / Release preparation

本轮范围以 [0.9.6 双语更新说明](v0.9.6.json) 为准：内置 DSH 更新至 0.2.1-rc.3，默认插件更新到兼容版本；新会话入口沿用官方的未发送草稿恢复行为。左侧栏、会话视图和右侧栏的“更多”菜单支持浏览和创建插件。聊天管理的归档会话页面统一设置样式。

升级继续保留现有会话、设置、凭据、插件和工作区。

The [0.9.6 bilingual descriptor](v0.9.6.json) covers bundled DSH 0.2.1-rc.3, compatible default plugin updates and the official recovery of unsent drafts through New Session. The More menus in the left sidebar, conversation view and right sidebar support browsing and creating plugins. Chat Manager aligns the archived-session page with the settings style.

Upgrades continue to preserve sessions, settings, credentials, plugins and the workspace.
