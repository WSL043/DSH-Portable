# 0.9.7 发布准备 / Release preparation

本批用户可见变化以 [0.9.7 双语更新说明](v0.9.7.json) 为准：插件可选的透明边缘缩放、更新通道状态和离线包说明，以及运行环境与依赖维护。不重复列入 0.9.6 已发布的 rc.3、新会话草稿和归档页功能。

发布仍受 [内置依赖安全门槛](../docs/bundled-dependency-security.md) 阻断。必须完成实际内联消费者验证、精确候选成品验收、整包本地升级与内核目录资格检查；不能以源码覆盖预览代替最终包，也不能为改变版本显示仅编辑组件清单。

The [0.9.7 bilingual descriptor](v0.9.7.json) covers optional transparent resizing, channel and offline-package guidance, and runtime/dependency maintenance. Features already shipped in 0.9.6 are not repeated. Publication remains blocked pending bundled-dependency qualification and final, coherent package acceptance.
