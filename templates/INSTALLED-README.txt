DeepSeek-Herness
================

中文
----

从开始菜单或桌面快捷方式打开 DeepSeek-Herness。

关闭窗口默认会收进系统托盘，正在执行的任务继续运行。右键托盘图标可以重新
打开窗口、完全退出，或把“关闭窗口时”改成直接退出。

设置、凭据、会话、插件、桌面数据和默认工作区保存在：

  %LOCALAPPDATA%\DeepSeek-Herness

升级或重新安装不会清除这些数据。卸载程序也会保留它们；只有在你确定要删除
所有本地 DSH 数据时，才手动删除这个目录。

插件可通过安装目录中的 dsh.exe 管理。插件变更不会自动打断正在运行的任务；
保存工作并从托盘完全退出，再重新打开后生效。

DSH 仅监听 127.0.0.1。数据目录可能包含 API 凭据和私人会话，请妥善保管。
这是独立社区分发的 DeepSeek Harness 桌面版本，并非 DeepSeek 官方桌面应用。

English
-------

Open DeepSeek-Herness from the Start menu or desktop shortcut.

Closing the window sends the app to the system tray by default so active tasks
continue. The tray menu can reopen the window, exit the app completely, or change
the close behavior to exit directly.

Settings, credentials, sessions, plugins, desktop data, and the default workspace
remain in:

  %LOCALAPPDATA%\DeepSeek-Herness

Updating, reinstalling, or uninstalling the application leaves this folder in
place. Delete it manually only when you also intend to erase all local DSH data.

Manage plugins with dsh.exe in the installation folder. Plugin changes never
restart an active task automatically; save your work, exit from the tray, and
reopen the app when convenient.

DSH binds only to 127.0.0.1. The data folder can contain API credentials and
private conversations. This is an independent desktop distribution of DeepSeek
Harness, not an official DeepSeek desktop release.
