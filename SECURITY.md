# Security policy

## Supported releases

Security fixes target the latest stable DSH-Portable release. Before reporting a problem from an older build, reproduce it with the current stable release when it is safe to do so.

## Report a vulnerability privately

Use GitHub [private vulnerability reporting](https://github.com/WSL043/DSH-Portable/security/advisories/new) for vulnerabilities that could expose credentials or conversations, execute unexpected code, bypass update verification, or affect another user's installation. Do not open a public issue for an unpatched vulnerability.

Include the DSH-Portable version, operating system, minimal reproduction, security impact, and whether the issue also exists in official DeepSeek Harness. Remove API keys, OAuth data, credentials, private conversations, and personal file paths from screenshots and logs.

Ordinary crashes, layout problems, and feature requests belong in the public issue templates.

---

## 安全策略

安全修复以最新版 DSH-Portable 正式版为支持基线。条件允许时，请先确认问题能否在当前正式版复现。

可能泄露凭据或会话、执行非预期代码、绕过更新校验，或影响其他用户安装环境的问题，请通过 GitHub 的[私密漏洞报告](https://github.com/WSL043/DSH-Portable/security/advisories/new)提交，不要在漏洞修复前公开 Issue。

报告请包含 DSH-Portable 版本、操作系统、最小复现、影响范围，以及官方 DeepSeek Harness 是否也存在该问题。截图和日志中必须移除 API Key、OAuth 数据、登录凭据、私人会话和个人文件路径。

普通崩溃、界面问题和功能建议请使用公开 Issue 模板。
