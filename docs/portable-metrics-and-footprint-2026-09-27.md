# 插件统计、日志与便携成本核对

本记录是 2026-09-27 的观测，不是长期稳定性或所有硬件的验收结论。

## 市场统计为什么对不上

市场读取 https://awesome-dsh-plugin.com/plugins.json 的社区目录快照。本机缓存与在线目录一致，目录标记 updated=2026-09-26；卡片没有直接逐条请求 GitHub/npm。重新同步目录不等于上游已经重新采集每项统计。

| 插件 | 目录 Star / 实时 GitHub | 目录 npm 下载 / 此次 npm API |
| --- | --- | --- |
| dsh-codex-subscription | 97 / 98 | 11974 / 13355 |
| dsh-chat-manager | 6 / 6 | 5393 / 6616 |
| dsh-image-viewer | 1 / 1 | 5296 / 6150 |

npm 本次 last-month 响应范围为 2026-08-27 至 2026-09-25。目录没有给出每条统计的采集时间，不能仅凭目录日期推定每项都在当天刷新。npm 下载、GitHub Release 附件下载、Star 是不同指标，不能相互对应，也不能以下载次数宣称独立用户数。npm 页面常见的周统计也不能直接和近 30 天值比较。

此次改动：卡片和详情数字的提示注明来源、近 30 天口径、非用户数和目录快照日期；added 改称收录时间，不再称发布时间。维持紧凑布局，不为实时数字逐条查询 4367 个条目。尚未安装到用户现用程序，不称为实机 UI 已验收。

### 随后按用户要求改为累计下载

卡片与详情不再使用目录里的 downloads（月下载），改为从 npm 首次发布时间至最新已结算日期分年度查询并求和。npm 官方接口每次最多 18 个月，历史最早至 2015-01-10；早于该日期的包显示可用历史累计并加 `+`，不冒充完整终身总量。缺数据或失败显示不可用，不回退为月下载或零。

只加载当前可见页/详情的包，服务端并发 4、队列最多 128、合并同包请求、进程内缓存 256 项/24 小时。前端卸载取消请求；不让统计阻塞目录。因为无法以部分已查询数据正确排序全部目录，移除月下载排序入口，默认按 Star 排序；没有声称具备全目录累计下载排名。GitHub Star 仍来自目录快照。

真实 API 核验：dsh-codex-subscription 累计 20469，2026-08-16 至 2026-09-25。这是 npm 下载次数，非用户数，也非 GitHub Release 附件下载。参考 https://github.com/npm/registry/blob/main/docs/download-counts.md 。源码及产物更新不等于用户当前安装已更新。

## 日志与市场开销

- 现用 data/logs 只读扫描：94 个文件，4368162 字节，约 4.2 MiB；没有删除任何内容。
- 历史日志已有单文件 128 KiB、30 次运行、14 天与 32 MiB 清理预算；未知文件/活跃记录受保护，所以预算不是对整个日志目录的强制总额上限。
- 原始 timestamp 使用 ISO UTC（Z），中国本地显示应加 8 小时。保留 UTC；展示层应注明本地时区，不能直接篡改时间戳。
- 原生健康诊断正常阶段约 30 秒落盘一次，主线程每秒心跳帮助识别阻塞。保留诊断价值，后续用 CPU/句柄趋势测量其成本再决定采样调整。
- 市场已经分页、memo 筛选和懒加载图片，Logo 复用官方素材。此次补 README 截图缓存最多 64 项、请求 8 秒超时，避免详情浏览无限保留缓存或悬挂网络请求。不是对浏览器总内存的上限承诺。
- registry.ts 中关于“只存内存”的旧注释已与实际磁盘快照机制对齐。

## 内存与体积基线

现用 Native 实例一次只读快照，包含用户插件和当前页面，非干净启动：

| 部分 | 私有内存 MiB |
| --- | ---: |
| Native 壳 | 41.8 |
| WebView2 六个进程合计 | 459.2 |
| portable-host / DSH 后端 | 338.9 |

私有内存不等同物理驻留内存，进程组总值也不能归因为 Portable 自己的代码。下一步应对同内核、同插件、同场景比较官方 web 与 Portable，记录空闲、20 次市场往返、图片开关、插件操作后的稳定值与退出残留，区分缓存平台值和持续增长。

已发布 0.7.5 标准 ZIP 中主要压缩条目：DSH-App.dshpack 112.02 MiB、node.exe 33.05 MiB；Native EXE 约 0.11 MiB。运行时已压缩，再压 ZIP 收益很小。删图标或精简文案不是主要瘦身路径。不能为缩小数字删掉官方语音/文档功能或破坏离线恢复。

## 产品取舍与可验收优势

1. 便携：新机器无需预装 Node/pnpm；移动目录后会话、插件与设置可继续使用。用干净环境和移动测试证明。
2. 可控：内核更新、插件更新与完整产品更新边界清楚；失败能恢复，支持报告能说明失败阶段。
3. 长用有界：自动整理安全可重建内容，用户数据与恢复材料受保护；空间页区分逻辑占用与可回收估计。
4. 少维护分叉：上游提供稳定能力就退掉对应适配，不另造聊天界面。容量、启动与内存按版本记录，退步必须有解释。
5. 推广只写已验证的优势，不声称比所有桌面产品更快更稳；比较需同环境、同功能和同数据。
