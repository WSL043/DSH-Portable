# 1.0.0 交付范围与验收

2026-09-26，用户调整为先推进 **1.0.0-alpha 内部开发线**，首个开发身份为 `1.0.0-alpha.1`。不创建 GitHub Release（包括预发布和草稿），不进入公开产品/内核更新列表，只保留源码、内部构建和验收产物。当前 Native 产品版本与稳定锁不跟随开发身份改号。全部交付门槛仍以未来 1.0.0 为目标；公开晋级按后续明确决定执行。设计依据为 [长期架构](portable-long-term-architecture.md)。

## 实施批次

1. 固定便携宿主构建、路径与进程边界，补正常退出及真实插件运行；形成可复现的独立开发成品。
2. 接入完整组合更新与独立恢复入口；补迁移预检、失败回退和数据格式边界。
3. 官方页面/插件能力接管，删除已被替代的补丁；完成空间治理及首用优化。
4. 用同一精确成品跑全部用户操作、旧环境升级、断网及失败注入；修复后只复跑受影响门槛与最终发布认证。
5. 本阶段生成内部验收与校验材料，不发布 Release 或公开更新。未来决定公开晋级后，再执行发行与公共索引验收。任何阻断均保留证据，不以版本号或绿色总状态替代验收。

开发批次沿用 A/T/U/S/Q 原任务，不重复勾选。当前 Native 修复可以独立交付；1.0.0 不要求永久维护两套功能对等桌面，也不扩张到通用多实例管理器、云同步或自研包管理器。

## 第一批实现证据

Electron 开发路径初始化新增写入前完整预检：任何受管目录或已有祖先为符号链接/Windows junction、或目录位置被文件占用时，拒绝启动，不先创建其他目录或改变 DSH_HOME/Electron 路径。这只防止已有路径意外重定向，不构成抵御并发本机写入者的沙箱。

5 项专项测试通过，含真实 Windows junction 拒绝与无部分初始化；RC2 真实来源覆盖层验证通过，官方更新器调用数为 0。将该 helper 应用到隔离官方 RC2 检出后，真实 Desktop TypeScript、主进程/preload 和 Welcome 构建通过。不是新的原生窗口、跨机迁移或发布验收；这些仍在上表。

## 第二批：真实开发宿主生命周期与页面往返

2026-09-26，在独立 Windows 桌面上启动编译后的官方 RC2 开发宿主，未操作用户前台窗口。欢迎页完成加载后向该进程的私有桌面窗口发送 WM_CLOSE：进程自行退出，退出码 0，未依赖超时强制结束。该结果只覆盖欢迎阶段正常关闭。

另一个全新隔离数据根通过官方“稍后配置”动作进入 `dsh-app://app/`，可见一个编辑器。官方“插件”按钮打开插件页，可见“添加插件”；再次启动同一隔离数据根，工作台有一个编辑器，插件页为零，点击官方“新会话”返回后恢复为一个。此处没有安装插件、提供密钥、发送模型请求或进行截图视觉验收，不能计为这些项目通过。

工作台首轮探针到达 65 秒保护期限被清理，晚到的后续命令返回连接拒绝；这是已知探针到期，不归因为产品崩溃。随后在新的有界启动中完整执行上述往返。工作台退出仍为强制保护清理，尚未证明带后端/任务的正常应用退出。内部 alpha 不产生公开 Release 或更新索引。

## 第三批：独立 Windows alpha.1 样包

2026-09-26，`package-alpha.mjs` 从已核对的 RC2 官方资源、Electron 44 和本地编译社区主进程生成独立目录。不分发官方 DeepSeek EXE 或更新源配置。开发包首次启动从 EXE 所在目录派生 `data`，不再要求环境变量或源码目录；开发更新和强制更新策略继续关闭。

成品已放到 `C:\Users\Omo\Downloads\DSH-Portable-1.0.0-alpha.1`。6 项路径/来源专项测试通过；官方 runtime-payload-smoke 用成品 Electron 执行成功，覆盖 koffi、sharp、HTML、PTY、pnpm、grep、glob。真实私有桌面完成输入文字、官方插件页往返、缺少 bundle 声明拒绝、合规本地测试包安装、启停、卸载；已卸载测试包。渲染截图人工检查通过，范围是亮色工作台和插件列表，不含外层原生窗口边框、暗色或 DPI。

样包从 build 移到 Downloads 后重启，保留输入草稿、工作台编辑器可见；无凭据时仍需在欢迎页选择“稍后配置”。最终通过 CDP Browser.close 请求退出，主进程自行退出码 0、forcedCleanup=false。此项不证明原生菜单、托盘及有任务时的退出确认。此前有界探针强制结束不计为正常退出。

尚未完成：默认插件具体功能及联网更新；账户/模型真实请求；旧数据迁移；组合更新与独立恢复；跨机器、macOS、暗色/DPI；存储治理及瘦身。独立样包约 1.07 GB（十进制，含少量验收数据），不能称为完成 1.0.0 或已达到正式发布标准。后续先完成这些门槛，再考虑公开晋级。
