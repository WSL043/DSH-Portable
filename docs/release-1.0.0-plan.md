# 1.0.0 交付范围与验收

2026-09-26，用户授权按重大架构升级推进，全部交付门槛通过后发布 1.0.0。当前仍处于开发阶段，不提前修改稳定锁、公开通道或成品版本号。设计依据为 [长期架构](portable-long-term-architecture.md)，本文件定义该设计第一次正式交付的范围。

## 必须交付

| 范围 | 1.0.0 完成条件 | 当前状态 |
| --- | --- | --- |
| 官方 Electron 便携宿主 | Windows/macOS 可重复构建；明确社区/官方签名身份；程序与数据独立；唯一更新所有者；不依赖开发检出 | RC2 开发宿主已能启动；分发构建、签名方案与正式更新仍待实现 |
| 旧用户迁移 | 真实旧版数据、附件、插件配置与工作区引用迁移通过；失败保留原环境；跨机允许重新登录 | descriptor-v2 仍按既有官方包阻断，不预改用户会话绕过 |
| 桌面操作 | 输入、会话切换、归档/恢复/删除、图片查看/标注、设置开关、窗口/托盘/退出；亮暗、DPI、焦点和键盘 | 不能沿用 Native 或旧源码验收当作 Electron 成品通过 |
| 插件生命周期 | 默认插件实际安装、旧版更新、启停、卸载、取消及故障恢复；官方页面只维护一套真实状态 | 开发宿主最终组合待验；未确定必要默认插件前不承诺永久保留两款 |
| 更新与恢复 | 下载中断、摘要错误、磁盘不足、占用、切换中断、健康检查失败；程序回退与数据恢复边界明确 | 复用原事务能力前需验证整套 Electron 组合适用性 |
| 长期存储 | 当前/回退/活跃/固定版本受保护；清理后真实断网重建；空间统计可解释 | 原存储待办继续，不接入破坏离线修复的 prune |
| 首用与性能 | 完整下载至首次可操作、后续启动、更新传输、内存/句柄趋势，与 Native 同机对照 | RC2 仅有压缩和解包基线，未完成整体性能验收 |
| 发布与支持 | 当前支持矩阵、已知限制、准确 README、公共更新索引回读；Linux Native 路线明确 | 待实际成品决定平台清单，不能给未验平台套 1.0 标记 |

## 实施批次

1. 固定便携宿主构建、路径与进程边界，补正常退出及真实插件运行；形成可复现的独立开发成品。
2. 接入完整组合更新与独立恢复入口；补迁移预检、失败回退和数据格式边界。
3. 官方页面/插件能力接管，删除已被替代的补丁；完成空间治理及首用优化。
4. 用同一精确成品跑全部用户操作、旧环境升级、断网及失败注入；修复后只复跑受影响门槛与最终发布认证。
5. 生成发行说明和校验材料，验证公共下载与更新发现，再发布 1.0.0。任何阻断均保留证据，不以版本号或绿色总状态替代验收。

开发批次沿用 A/T/U/S/Q 原任务，不重复勾选。当前 Native 修复可以独立交付；1.0.0 不要求永久维护两套功能对等桌面，也不扩张到通用多实例管理器、云同步或自研包管理器。

## 第一批实现证据

Electron 开发路径初始化新增写入前完整预检：任何受管目录或已有祖先为符号链接/Windows junction、或目录位置被文件占用时，拒绝启动，不先创建其他目录或改变 DSH_HOME/Electron 路径。这只防止已有路径意外重定向，不构成抵御并发本机写入者的沙箱。

5 项专项测试通过，含真实 Windows junction 拒绝与无部分初始化；RC2 真实来源覆盖层验证通过，官方更新器调用数为 0。将该 helper 应用到隔离官方 RC2 检出后，真实 Desktop TypeScript、主进程/preload 和 Welcome 构建通过。不是新的原生窗口、跨机迁移或发布验收；这些仍在上表。
