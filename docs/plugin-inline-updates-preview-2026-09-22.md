# 插件更新行内预览 · 2026-09-22

## 实现

移除独立插件更新弹窗。官方插件卡片名称旁显示版本变化，更新/重试/待重启操作与原启用开关同一行。保留官方列表、说明、详情和启用功能；没有更新时不增加行高。进入插件页自动检查，使用五分钟缓存。移除独立检查按钮，原有刷新图标同时刷新官方列表和插件更新；失败只显示简短提示，不宣称已是最新。多个卡片共享进行中状态，重复点击不能发起第二次更新；更新完成不触发官方 inventory refresh，避免提前跳离插件页。

## 验证与交付边界

- 客户端构建通过；native-settings-command 与 bundled-plugin-updates 共 10 项测试通过。
- 实际 3080 服务返回订阅插件 2.1.3-beta.1 → 2.1.3、context 0.54.0 → 0.54.2，行内显示可见。
- 更新失败、重试、成功待重启及窄窗口通过浏览器响应模拟验证；没有更新用户任何插件，不能据此宣称真实包安装已验收。
- 安装本地 UI 预览后，使用无响应替换的后台 Chrome 连接实际服务；从插件页切换已有会话再返回通过，前端异常为零。原生刷新按钮触发一次强制更新检查，返回 200；确认顶部没有独立检查更新按钮。
- 验收脚本最初把再次点击插件导航视为关闭，实际官方导航不会切换关闭；改为点击已有会话验证离开。这是验收步骤纠正，不修改官方导航语义。
- 未控制前台鼠标/键盘，原生窗口由用户手动验收。
- 仅替换当前运行缓存内 plugin manager client 与 Portable market client；原文件保留于 build/plugin-update-review/original。原始 runtime capsule 未改，本地修复或重新生成运行缓存会恢复发布版本。没有公开发布。

证据：build/plugin-update-review/evidence.json、installed.json、installed-acceptance.json、installed-dark.png。用户数据、会话、插件启用状态保持不变。
