# 插件更新与归档删除交付检查

## 原问题与修复

用户现有安装的启动日志连续记录默认插件升级失败：离线重建整个 profile 时，订阅插件版本未被缓存元数据识别，连带阻断两个默认插件升级。会话插件仍为 1.3.5，无法以新宿主的归档删除验收结果代表用户已经收到功能。

现代官方插件页的 Portable 扩展此前只提供市场浏览，遗漏独立更新入口。现在增加“插件更新”操作，只处理更新，安装、启用、卸载仍由官方页负责。更新沿用现有任务互斥、活动任务保护、精确版本校验和失败回滚，不新增包管理器。对默认会话和图片插件，优先提供当前 Portable COMPONENTS 中配套且比已安装版本更新的版本；不让其他插件自动选择预览版，不替换外部或本地来源。

更新弹窗自身保留进行中的操作状态，关闭再打开不会重新发起更新；关闭弹窗不是取消后端任务。界面明确要求保存工作并重启、检查启用状态，不自动开启用户禁用的插件。

- TypeScript、服务端和客户端构建通过；76 项定向测试通过。

- 重新启用会话插件并显式重启宿主后，设置归档页显示红色“永久删除”。取消删除无删除请求，确认仅删除合成会话；恢复归档、关闭后输入、重复开关无额外弹窗通过。
