# 把 DSH-Portable 移到另一台电脑

[English](move-between-computers.en.md)

DSH-Portable 的会话、设置、插件和默认工作区都保存在便携目录中。完整退出后复制目录，就能在另一块硬盘、U 盘或电脑上继续使用。

## 移动整个工作环境

1. 在托盘菜单选择 **退出 DeepSeek Harness**。
2. 等待窗口和托盘图标消失。Windows 用户还应等到文件夹可以正常重命名；不要在程序仍运行时强制复制或删除。
3. 复制整个 `DSH-Portable` 文件夹到新位置。
4. 在新位置运行 `DeepSeek-Herness.exe`。macOS 运行应用包；Linux AppImage 用户同时复制旁边的 `DSH-Portable-data` 目录。
5. 打开一个已有会话，再检查常用插件和默认工作区。Portable 会修正它管理的旧路径；你主动打开的外部项目仍保留原位置。

不要让两台电脑同时运行同一个同步目录。会话正在写入时由网盘或同步工具合并同一份数据，可能产生冲突。

## 只迁移个人数据

不想复制完整运行环境时，打开 **设置 → 通用设置 → 便携版 → 数据与迁移**：

- **导出迁移包**：便于在你信任的设备之间迁移。
- **导出加密私密包**：内容相同，但需要密码才能读取，更适合云盘或移动介质。

两种包都包含会话、设置、插件配置和 API 凭据；都不包含运行时、缓存、日志或工作区文件。未加密迁移包属于敏感数据，不要公开分享。

导入到已有环境时，默认只补入缺失数据。明确选择覆盖前，Portable 会在 `data/backups/` 创建回滚副本。

## 不用第二台电脑也能验证

1. 新建一个测试会话，并确认一个插件处于启用状态。
2. 从托盘完全退出。
3. 把整个文件夹移动或重命名，例如从 `Downloads` 移到 `Documents`。
4. 从新位置重新打开，确认测试会话、插件和设置仍然存在。

这个检查只验证 Portable 管理的数据。你在其他位置打开的代码仓库、图片或文档不会被复制进便携目录。

## 移动前检查

- Windows 移动盘优先使用 NTFS，避免文件权限、长路径和单文件大小限制。
- 更新或修复正在进行时不要移动目录。
- 如果 Windows 提示文件仍被占用，重新打开 DSH-Portable，运行 **设置 → 通用设置 → 便携版 → 运行检查**，再从托盘完全退出。
- 遇到无法解决的问题，可在同一页面导出脱敏支持报告并[提交 Bug](https://github.com/WSL043/DSH-Portable/issues/new?template=bug-report.yml)。不要附带 API Key、未加密迁移包或私人会话。
