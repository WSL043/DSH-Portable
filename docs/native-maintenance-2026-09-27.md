# Native 维护闭环：迁移回滚与存储查询

本批延续已发布的 0.7.5 Native 主线，不扩展插件市场设计，不推进 Electron 功能。

## 实现与故障验收

- 页面退出时取消未完成的工作区选择请求；迟到回复不能影响新请求，卸载移除监听器。WebView2 与通用原生桥接均有行为测试。普通长时间选目录不增加强制超时。
- 导入回滚不再吞掉删除失败。新文件或生成目录被占用时，明确返回 `DSH_DATA_IMPORT_ROLLBACK_FAILED`，保留备份，不能继续无插件降级重试。
- 回滚先检查所有必要备份。备份缺失时保留当前文件和剩余恢复材料，不能删除当前内容后误报成功。检查之后备份又消失，实际恢复操作仍报错。
- 故障测试在真正的原子写入过程中写入部分字节后注入 `ENOSPC` / `EIO`：先前替换的文件恢复，未完成目标保持旧内容，临时文件清除。另覆盖真实目录阻挡、`EBUSY` 和丢失恢复文件。没有通过填满用户磁盘模拟故障，也不声称验证了物理断电。
- 存储接口使用真实扫描模块验证独立 stateRoot：四类字节数、profile 操作日志和工作区排除均正确。原有链接保护及大 store 扫描预算测试继续通过。

最终本地全仓记录 `build/native-maintenance-final-tests-20260927.txt`：889 项，875 通过、14 条件跳过、0 失败。其中 Windows 文件 symlink 权限限制由跨平台 CI 独立覆盖，不将本地跳过计作通过。
