# 缓存与启停稳定性验收

日期：2026-09-12。范围为 `0424632` 后的缓存报告和 Windows 退出检查修复；版本号仍为 0.6.7，本记录不是发布资格声明。

## 发现与处理

- 缓存状态查询原先会顺带删除失效租约，现改为只读，回收交给受锁保护的清理流程。统计补入中断解包目录，并明确报告部分读取失败，避免把不完整统计当作完整占用。
- 无法识别所有者的损坏租约保留；对于本程序生成的 UUID 租约文件名，可以恢复中断写入前记录的 PID，但仍须确认进程退出才回收。
- 实机反复操作完成后的 `stop` 报错：Windows 进程查询返回无效元数据。原始日志没有保留 CIM 原文，因此不能声称它完整证明了竞态原因。针对退出期间命令行为空的合法状态增加独立 PID 检查：仅确认 PID 不存在时视为退出；进程仍存活、权限不明或 JSON 损坏仍报错。回归测试覆盖这些分支，实机后续启停通过。
- 市场验收脚本原先在清理之前写入通过标志，导致停止失败时产物仍标记通过。现将停止错误纳入最终结果；保留原失败产物，不改写为通过。
