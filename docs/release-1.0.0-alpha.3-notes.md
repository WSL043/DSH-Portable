# 1.0.0-alpha.3 — 官方桌面便携边界开发版

**仅保留为开发草稿，不进入公开 Releases，也不替代 0.7.x 稳定版。** 使用全新目录，不覆盖 alpha.2 或导入旧 data。

这次修复 alpha.2 的两个主要缺口：浏览器通过 `dsh://` 返回时绕过便携启动器，以及官方检查更新入口缺少可用更新源。更新仍使用官方界面与任务关闭协调器，Portable 接管下载、验签、解包、暂存和重启切换，不运行安装器。

官方 EXE 和运行库保持原字节。ASAR 的主进程增加小范围边界适配，修改前后摘要随包记录。此版不能称为完全未经修改的官方程序；官方 EXE 的签名也不代表官方认可整个社区发行包。上游适配位置变化会停止自动投递，等待审核。

验收使用一次性 Windows runner 的真实桌面程序，检查输入、插件安装启停、搬迁后的草稿与卸载、协议回跳、更新状态与失败重试、原生重启、退出和目录外写入。以随包 `qualification.json` 绑定的成功运行及证据为准，不以源码单测代替成品验收。

当前开发边界：固定端口 19387 仍不能与其他 DSH 实例共用；工作区仍沿用官方外部路径；协议关联在移动后需先运行启动器重新注册。Windows 系统记录和临时文件不承诺全部留在目录内。跨机器账号、历史数据迁移、全部第三方插件和物理断电恢复没有完整保证。同版本更新检查不等于两个不同官方版本的升级验收。

程序、适配和受管状态的归属见随包 README；账号和凭据可能位于 data，请勿公开分享。
