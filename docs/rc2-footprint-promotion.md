# rc.2 安装包体积预算接入

0.7.8 首轮 CI `36376659710` 的 macOS ARM 产物被 alpha.1 的稳定分项预算拦下，原失败记录保留：非 Office 292,408,045 字节（旧上限 290,000,000），非 Office/语音 258,318,401 字节（旧上限 255,000,000）。总解包 444,944,021 字节、ZIP 158,863,245 字节，市场 390,845 字节，均未触及总量上限。

与已发布 0.7.7 的同平台 `footprint-macos-arm64.json` 逐包比较：官方账号界面增加 5,177,478 字节，Web 前端增加 912,580 字节，新增 Temporal polyfill 939,551 字节；调度界面及后端另增加 292,359 和 194,468 字节。增长来自官方运行时，不删账号、调度或语音功能来满足旧预算。

稳定预算采用已有候选预算的非 Office/语音分项额度（macOS/Linux 增加 6 MB，Windows 相应分项增加 8–9 MB）。总压缩包、总解包、文件/目录数、Office、语音及市场上限全部保持不变。新提交必须重跑所有平台体积检查和成品验收；此记录不是绕过失败的发布许可。
