子代理只读核对发现，基线前每类操作只预热一次，末段还保留了更多对话节点；两端并非完全等价的 UI 状态。这不能直接证明内存泄漏，也不能将失败改为通过。下一步只做定位对照，不重复无改动的两小时测试。

执行边界：仅后台隐藏窗口、私有缓存与合成数据，不控制前台、不使用真实模型凭据。保留已通过且不受影响的证据；不把长期路线研究继续加入本批门槛。
