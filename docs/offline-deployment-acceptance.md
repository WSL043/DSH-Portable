0.6.5 已于 2026-09-10 发布：[正式版与下载](https://github.com/WSL043/DSH-Portable/releases/tag/v0.6.5)。

## 两种 Windows 包

| 包 | 浏览器运行时 | 模型 |
| --- | --- | --- |
| 标准 ZIP，58,594,027 字节 | 需要系统 WebView2 | 自备模型服务与权重 |
| 完整离线 ZIP，357,466,892 字节 | 内含 Microsoft WebView2 152.0.4191.62 x64 | 自备模型服务与权重 |

两者均内含 Node、官方 DSH 0.1.5-rc.1、插件市场及默认插件所需的离线依赖。完整包不安装系统 WebView2，首次在本机缓存准备随包运行时。其压缩容器约 285 MiB，展开缓存约 798 MiB；标准包不会因此增加相同体积。

## 已完成的验证

- [35 项最终 CI 任务全部通过](https://github.com/WSL043/DSH-Portable/actions/runs/34468824144)，发布直接使用该次验收附件，提交为 `96b26e061a381a166fc07daa3774a4f14a8c4d59`。
- Windows 2022/2025 原生窗口、主题、日志、升级、移动和插件管理通过；完整离线包在全新原生窗口中明确使用随包 WebView2 并进入工作区。
- 本机 Win11 使用最终标准 ZIP 和全新运行时缓存，约 9.35 秒进入工作区。证据：`build/release-0.6.5-native-evidence/`。
- 同一最终包使用 LM Studio / Qwen3.5-4B，通过文件读取工具返回提示词未提供的随机内容。Node 非回环 TCP 拒绝启用，退出码为 0，没有外网连接尝试。证据：`build/release-0.6.5-model-evidence/result.json`。
- 空数据、空运行时缓存的默认插件离线安装检查已纳入 Windows CI；外部地址负向探测验证拒绝夹具确实启用。
- 全包升级保留已有随包 WebView2；新包含有新版运行时则优先使用新版。复制在 staging 完成，原版本保留用于回滚，对应 Windows 升级回归通过。

上述网络夹具仅限制 Node 的外网 TCP，不覆盖浏览器、LM Studio 或非 Node 子进程。因此不将结果描述为整机物理断网、无系统 WebView2 裸机或任意企业隔离环境认证。Windows Server CI 也不等同于 Windows 10 实机覆盖。

## 部署前需要准备

准备本地模型服务、模型权重及任务所需的外部工具；若使用企业内网服务，仍需内网可达。在线模型、远程搜索、远程 MCP、下载新插件及在线更新需要对应网络。默认插件依赖已预置，不代表任意第三方插件都能离线安装。

企业镜像应在目标权限和隔离策略下验证首次启动、模型选择、流式回复、本地工具、取消、重启、会话恢复、移动与独立修复，并保留模型版本和运行日志。[离线功能请求 #128](https://github.com/WSL043/DSH-Portable/issues/128) 保留用于跟进原环境反馈。

## 构建与维护

- `scripts/build-windows-complete-offline.ps1` 检查底包产品版本、官方内核版本和提交，拒绝陈旧底包。
- `config/webview2-runtime.lock.json` 固定微软来源和 SHA-256；构建检查微软签名，保留全部运行文件。固定版需由后续完整包更新，不能假设系统会自动更新它。
- `scripts/default-plugin-store/pnpm-lock.yaml` 固定默认插件离线依赖。默认插件升级时同步审查此锁；构建拒绝锁与压缩包不一致的组合。
- 解包保留完整校验、原子提交和有界写入队列；再次启动复用缓存。小样本中的约 8% 准备阶段改善不是跨设备性能承诺。
- Windows 合约曾出现 PowerShell CIM 10 秒超时。限制测试文件并发为 2 后最终 CI 通过，产品超时和断言未放宽；负载争用仍是解释假说，不能只凭一次通过认定根因。
